# fernandopiras.com

Personal site and product portfolio for **Fernando Piras** — iOS Software Developer based in Bologna, Italy.

Live site: [https://www.fernandopiras.com](https://www.fernandopiras.com)

## What this repository is

Source for the public website: case studies for shipped App Store products, services pages, and technical writing.

It is not an application backend. Product commercial source code lives in private repositories.

## Stack

- Next.js (App Router)
- TypeScript
- React
- Tailwind CSS
- Framer Motion
- Deployed on Vercel

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint
npm run build
```

## Content

Site copy and product metadata are centralized under `src/config/` (for example `site.ts`, `blog.ts`, `servizi.ts`).
