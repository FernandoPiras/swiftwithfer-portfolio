## Engineering Principles

1. **Ship real products** — Prefer App Store releases over unfinished demos.
2. **Clarity over novelty** — Interfaces should be obvious under real use.
3. **Privacy by design** — Sensitive data stays controlled; permissions stay explicit.
4. **Own the full loop** — Discovery, design, build, test, release, and iteration.
5. **Evidence over adjectives** — Working software carries the claim.
